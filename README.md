PyOptimize 🐍

ابزار تحلیل ایستای کدهای پایتون و ارائه پیشنهادهای بهینه‌سازی

📌 معرفی پروژه

PyOptimize یک پروژه آموزشی با زبان Python است که با استفاده از تحلیل ایستای کد، ساختار برنامه را بررسی می‌کند و برخی مشکلات احتمالی مربوط به صحت نحوی، عملکرد و امنیت را شناسایی می‌کند.

هدف پروژه، کمک به برنامه‌نویسان برای شناخت بهتر کد و یادگیری روش‌های بهینه‌سازی است.

✨ قابلیت‌ها

- تشخیص خطاهای نحوی کد پایتون
- شناسایی حلقه‌های تو در تو
- بررسی آزمون‌های عضویت داخل حلقه‌ها
- هشدار درباره استفاده از "eval()" و "exec()"
- شناسایی برخی الگوهای مرتبط با مصرف حافظه
- ارائه تخمین اولیه از پیچیدگی زمانی و فضایی
- ارائه پیشنهادهای متنی برای بررسی و بهبود کد

🚀 روش اجرا

ترمینال را در پوشه پروژه باز کن و دستور زیر را اجرا کن:

python analyzer.py example.py

به‌جای "example.py" نام فایل پایتونی را قرار بده که می‌خواهی بررسی شود.

برای مثال، فایلی با نام "sample.py" بساز و کد زیر را داخل آن قرار بده:

def find_matches(items, targets):
    matches = []

    for item in items:
        if item in targets:
            matches.append(item)

    return matches

سپس اجرا کن:

python analyzer.py sample.py

ابزار گزارشی شامل ساختارهای شناسایی‌شده، هشدارها و تخمین‌های اولیه پیچیدگی نمایش می‌دهد.

🔍 روش تحلیل

PyOptimize از ماژول استاندارد "ast" پایتون استفاده می‌کند تا کد را به درخت نحوی تبدیل کند و ساختارهای آن را بررسی کند.

این روش بدون اجرای کد ورودی، برخی الگوهای قابل توجه را شناسایی می‌کند.

📊 تحلیل پیچیدگی

پیچیدگی زمانی

پیچیدگی زمانی نشان می‌دهد با افزایش اندازه ورودی، تعداد عملیات الگوریتم چگونه رشد می‌کند.

نمادهایی مانند "O(n)" و "O(n²)" برای توصیف این رشد به کار می‌روند.

پیچیدگی فضایی

پیچیدگی فضایی میزان رشد حافظه مورد نیاز الگوریتم را با افزایش اندازه ورودی توصیف می‌کند.

تخمین دقیق این دو نوع پیچیدگی به الگوریتم، اندازه ورودی و رفتار توابع وابسته است.

⚠️ محدودیت‌ها

- ابزار از تحلیل ایستا و قواعد ابتکاری استفاده می‌کند.
- همه خطاهای منطقی یا خطاهای زمان اجرا را تشخیص نمی‌دهد.
- تخمین پیچیدگی زمانی و فضایی قطعی نیست.
- زمان اجرا و مصرف واقعی حافظه را اندازه‌گیری نمی‌کند.
- کد ورودی را به‌صورت خودکار اصلاح یا بهینه نمی‌کند.
- هشدارها باید توسط برنامه‌نویس بررسی شوند.
